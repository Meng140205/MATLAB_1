# MATLAB 双臂协同抬升 30 cm：离线闭环仿真

运行入口是 [`run_closed_loop_30cm.m`](run_closed_loop_30cm.m)。它不连接 ROS 2 或 Gazebo，也不调用 Python。MATLAB 用当前计算出的力矩推进双臂和棍子的动力学状态，并在下一个 50 ms 周期用新状态重新求解 MPC。参考状态只用于构造跟踪目标，不被写回仿真对象。

## 运行

在 MATLAB R2023b 中执行：

```matlab
cd('D:/myChatGPT/Transport2')
report = run_closed_loop_30cm;
```

需要 Optimization Toolbox 的 `lsqnonlin` 和 `quadprog`。默认仿真 62 s：60 s 内抬升 0.30 m，随后保持 2 s。可先用 `run_closed_loop_30cm('simDuration',1)` 做短时检查。结果保存在 `results/`，包括 `.mat` 全量数据、`.csv` 轨迹和四组 PNG/FIG 图。

## 使用的模型

- 双臂各 6 个关节；URDF 连杆、冻结在 0.01 m 的手指惯量、棍子 SDF 的 0.15 kg 质量和惯量均来自先前模型快照，副本位于 `model_data/`。
- 起始关节角和棍子位姿采用先前无支撑稳定抓取记录。两侧固定抓取变换在初始状态捕获。当前离线场景默认无支撑。
- 采用先前的 18 维约束动力学、36 维局部状态、12 维完整关节力矩输入；MPC 预测 10 步，每步 0.05 s。`+dualarm/` 中的数学核心与先前 MATLAB 候选版一致。
- 参考为 60 s 五次多项式 30 cm 竖直抬升、61 点双臂 IK、PCHIP 关节插值；x/y 和棍子姿态保持初值。
- QP 目标、约束、摩擦前馈、启动余量和有界残差估计沿用上传的模型文档。受约束求解使用 MATLAB `quadprog`。

## 这一版离线对象的边界

离线对象用同一刚性抓取约束动力学积分实际状态，额外施加每关节幅值不超过 `0.02 N·m` 的确定性扰动，以检验反馈闭环；这是**理想刚性抓取加小扰动**的仿真。它没有接触摩擦锥、指尖滑移、Gazebo 的关节静摩擦、网格碰撞或 ROS 2 通信延迟。离线对象的关节摩擦暂按当前参考速度的平滑经验模型施加，因此不能用此结果判断此前 Gazebo 第 4 关节启动停滞已经解决。后续可先以这组图为 MATLAB 基线，再用 Gazebo 实测轨迹比较和改进对象模型。

源码文件放在当前工作区；没有修改虚拟机的 `ros_workspace/src`。

## 本机验证记录

在 Windows MATLAB R2023b 上完成 62 s 全程运行：实际抬升 299.977 mm，三维位置误差峰值 0.114 mm，最大关节误差 0.000602 rad，最大棍子姿态误差 0.0317°，离线验收为 `true`。QP 求解墙钟时间中位数约 4.88 ms、95 分位约 10.89 ms，但 1240 次中有 25 次超过 50 ms，最慢约 2343 ms。离线结果说明算法在当前理想化动力学对象上完成 30 cm；这些超时及对象模型差异使它还不能直接视为 Gazebo 实时执行通过。
